Reliable, accurate, queryable REST API request/response logs for WordPress — without the wp_posts bloat.

== Description ==

Better REST API Logs captures every inbound REST API request and response into dedicated custom database tables — not the WordPress posts table. Designed for developers, site administrators, and integrators who need reliable visibility into REST API behaviour without the database bloat and broken filters of older logging plugins.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/` or install via the WordPress.org plugin search.
2. Activate the plugin through the **Plugins** menu in WordPress.
3. Visit **Tools → REST API Logs** to view captured requests.

== Frequently Asked Questions ==

= Does this plugin send data anywhere? =

No. All captured data stays on your site. The plugin makes zero external network calls.
